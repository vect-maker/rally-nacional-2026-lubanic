# rally-nacional-2026-lubanic

## Presentation Slides

The slides are built with [Typst](https://typst.app/) and `@preview/touying:0.8.0`.

### Commands

```bash
just           # List all available recipes
just compile   # Compile slides to PDF
just watch     # Live reload / recompile on file save
just preview   # Export slides as images for visual inspection
```
